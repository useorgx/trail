# README preview provenance

`ledger-demo.png` was captured on 2026-10-14 from commit `3ded13894d56428e9e8fa944d944ee2993cb8351` (Trail 0.7.1). It is a 1440 × 700 PNG of the shipped browser ledger, with one repeated failure expanded to show its suggested fix.

The data comes entirely from `src/demo.mjs`: 48 made-up sessions across five projects, generated by the shipped `node bin/trail.mjs --demo` command. A copy of that temporary synthetic store was served through `node bin/trail.mjs open` using an isolated `TRAIL_HOME`. No client histories were scanned, no customer data was used, and nothing was uploaded.

Capture used Playwright Chromium in an isolated context with external requests blocked. The browser opened the normal per-launch tokenized loopback URL; that token is not stored in this repository. The terminal demo deletes its temporary store when you quit. For a normal browser preview, scan the local histories you choose, then run `trail open` and follow its printed URL.
